# Design references

هذا المجلد مخصص للقطات المرجعية التي سيرسلها مالك A.SYRIA.

- أضف لقطات الشاشة الأصلية هنا؛ لا تضغطها ولا تقص التفاصيل المفيدة مثل المسافات وشريط الحالة.
- استخدم أسماء وصفية مثل 01-home-dashboard.png و02-floating-navigation.png و03-vault-list.png.
- إذا كانت اللقطة لحالة معينة (محدد، موسع، تحميل، خطأ، لوحة مفاتيح ظاهرة)، اذكر الحالة في اسم الملف أو في ملاحظة قصيرة.
- الصور مراجع تصميمية وليست أصول إنتاج؛ لا تنسخها إلى موارد drawable أو raw في Android.
- لا يبدأ التنفيذ قبل مراجعة الصور وربطها في DESIGN.md الموجود في جذر المشروع.
